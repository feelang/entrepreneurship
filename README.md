# Self Discipline Toolbox

The [web edition](https://feelang.github.io/entrepreneurship/) contains the mini
program's cognitive biases, habits, life and work principles, and business topics.

Edit the Markdown in [content/](content/), then regenerate the website:

    npm ci
    npm run build

Open [docs/index.html](docs/index.html) for a local preview. GitHub Pages serves
`docs/` from the `pages-content` branch. Commit the Markdown and site output
together when publishing updates.
